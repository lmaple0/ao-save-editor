# Ao Save Editor v1.1.0

本版新增《碧之轨迹》NISA PC 与云豹 CLE Kai PC 存档编辑及双向转换支持。用户已在两版游戏内验收双向转换，确认功能基本正常。

## 更新内容

- 完整读取和保存 CLE Kai `NNN_save.bin`，统一复用现有角色、装备、回路、背包及进度编辑功能。
- NISA `savedata.dat` 与 CLE Kai 存档双向转换，完整迁移场景线程、128 个实体及尾段数据。
- CLE 同格式保存保留原文件专有字段；无修改保存可保持字节一致。
- 存档侧栏分别检测 NISA 与 CLE 本机目录，显示数量并切换列表。
- 转换时生成列表附属信息、复制已有缩略图，保留已有目标 CLE 索引中的其他槽位。
- 修正难度字段读取，普通终章存档不再被误标为通关资料。

## 使用

下载 `AoSaveEditor-v1.1.0-windows-x64.zip`，解压后运行 `AoSaveEditor.exe`，无需安装 Python。
也可直接下载单文件 `AoSaveEditor.exe`。

打开源存档，使用工具栏“转为 NISA”或“转为 CLE Kai”选择输出位置。
CLE 文件名使用 `001_save.bin` 至 `100_save.bin`。NISA 普通槽位为 `data0001` 至 `data0200`，通关资料为 `data0201` 至 `data0210`。
输出到实际 CLE 存档目录时，编辑器会合并已有 `info.bin`，保留其他槽位。

仅支持《碧之轨迹》NISA / CLE Kai PC 格式；本版不包含《零之轨迹》及独立系统存档转换。
没有提供的原始缩略图、地点索引和对话记录无法完整恢复；成就状态沿用源存档，不会因转换自动解锁。
