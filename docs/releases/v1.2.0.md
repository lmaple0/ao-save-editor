# Ao Save Editor v1.2.0

## 中文

本版改善首次启动的语言体验，并新增独立的物品添加功能。

### 更新内容

- 首次启动按系统 UI 语言选择界面：中文、日文系统使用对应语言，其他语言默认英文。
- 手动切换语言后记住选择，下次启动优先使用保存的语言，无需反复选择。
- 物品页新增“添加物品”窗口，可按名称或代码搜索完整目录，并查看当前持有数量。
- 未持有物品可直接新增；已持有物品按输入数量累加，不替换其他物品。添加后的总数量不能超过 99。
- 背包列表的“全部显示”更名为“清除筛选”，明确区分持有物品列表与完整目录。
- 新窗口及提示支持中文、英文、日文，修正非中文首次启动时的状态栏翻译。

### 使用方法

打开存档后，在物品页点击“添加物品”，搜索并选择物品，输入添加数量，再点击“添加物品”。窗口可保持打开以继续添加；完成后关闭窗口并保存存档。

添加已有物品会累加数量，例如持有 3 个、添加 2 个后变为 5 个。原有“编辑选中物品”的替换功能保持独立。

语言可随时在工具栏切换。Windows 用户设置保存在 `%LOCALAPPDATA%\AoSaveEditor\settings.json`，与游戏存档分开。

### 验证

- 18 项相关测试通过，覆盖系统语言映射、偏好保存、添加未持有物品、已有数量累加及数量限制。
- 发布源码完整回归：150 项运行，149 项通过，1 项依赖未公开私人样本而跳过。
- NISA/CLE 实际添加窗口验证通过；原有物品保持不变，添加后保存并重读一致。
- 英文／日文启动、界面切换及重启恢复语言选择验证通过。

下载 Windows EXE 或 ZIP，无需安装 Python。本版保留此前的怪物图鉴修复和 NISA ↔ CLE Kai 互转功能。

## English

This release improves first-launch language selection and adds a dedicated item-addition workflow.

### Changes

- On first launch, the editor uses Chinese or Japanese for matching system UI languages and English for all other languages.
- Manual language choices are remembered and take priority on subsequent launches.
- The Items tab now has an **Add Item** dialog. Search the full catalog by name or code and view currently owned quantities.
- Add items you do not own, or increase the quantity of an existing item, without replacing other inventory entries. The resulting quantity cannot exceed 99.
- The inventory list's **Show All** button is renamed **Clear Filter**, distinguishing the owned-item list from the full catalog.
- New dialog labels and messages support Chinese, English, and Japanese. The startup status bar now uses the selected language as well.

### Usage

Open a save, select the Items tab, and click **Add Item**. Search for and select an item, enter the quantity to add, and click **Add Item**. Keep the dialog open to add more items, then close it and save the file.

Adding an owned item increases its quantity: owning 3 and adding 2 results in 5. The existing **Edit Selected Item** replacement workflow remains separate.

Change the language at any time using the toolbar. Windows preferences are stored at `%LOCALAPPDATA%\AoSaveEditor\settings.json`, separately from game saves.

### Verification

- 18 focused tests passed, covering system-language mapping, saved preferences, missing-item addition, quantity accumulation, and quantity limits.
- Full source-package regression: 150 tests run; 149 passed and one private-sample-dependent test skipped.
- The actual Add Item dialog was verified with both NISA and CLE saves. Existing items remained unchanged, and the results survived saving and reloading.
- English/Japanese startup, language switching, and preference restoration after restart were verified.

Download the Windows EXE or ZIP; no Python installation is required. The previous monster-manual fix and NISA ↔ CLE Kai save conversion remain included.
