# Ao Save Editor v1.1.1

## 中文

修复怪物图鉴显示“全资料”，但游戏内没有完成勾选、地属性有效率仍为 `???` 的问题。适用于 NISA 与 CLE Kai 两版《碧之轨迹》。

## 修复内容

- 完整状态按两版游戏代码判定，同时检查资料位、普通／高阶属性调查位，以及实际存在的掉落是否已调查。
- 移除旧 BZH `08 FE FF FF` 的错误完整判定，该值缺少地属性调查位。
- 设为全资料时补齐调查位，保留原有击破次数、高阶属性及掉落存在标记。
- 已完整条目保持不变；重复记录保留各自计数和标记。

## 已被旧版修改过的存档

用新版打开存档，选择受影响的怪物，执行“选中 → 全资料”并保存；也可使用“一键全开怪物图鉴”。
旧 `08 FE FF FF` 条目会补齐为 `08 FF FF FF`，只改变缺少的地属性调查位。
仅打开存档不会自动修改记录。

- 发布源码完整回归：145 项运行，144 项通过，1 项依赖未公开私人样本而跳过。
- NISA/CLE 复现副本保存重载通过，解密数据仅改变目标条目的地属性位。
- GUI 的“选中 → 全资料”操作验证通过。
- 用户已确认本地修复版正常。

下载 Windows EXE 或 ZIP，均无需安装 Python。NISA ↔ CLE Kai 互转功能保留。

## English

Fixes monster records labeled **Full data** while the in-game completion checkmark is absent and Earth efficacy remains `???`. Applies to both the NISA and CLE Kai PC editions of **Trails to Azure / Ao no Kiseki**.

### Fixes

- Completeness now follows the game predicate in both editions, checking information flags, normal/higher-element observations, and whether existing drops have been investigated.
- The legacy BZH payload `08 FE FF FF` is no longer incorrectly accepted as complete: its Earth observation bit is missing.
- Applying Full data fills observation flags while retaining defeat counts, the higher-element marker, and drop-existence flags.
- Already-complete entries are unchanged. Duplicate records retain their individual counters and flags.

### Saves edited with older versions

Open the save in this version, select the affected monsters, apply **Full data**, and save. You can also use **Unlock all monster records**.
Legacy `08 FE FF FF` entries become `08 FF FF FF`, changing only the missing Earth observation bit.
Opening a save alone does not modify its records.

### Verification

- 27 focused regression checks passed, covering element/drop conditions, legacy-record repair, counter/flag preservation, and both save containers.
- Full source-package regression: 145 tests run; 144 passed and one private-sample-dependent test skipped.
- NISA/CLE reproduction copies passed save/reload verification; only the target entry's Earth bit changed in the decoded payload.
- The GUI Full data action was verified.
- The user confirmed the local repaired build is working.

Download the Windows EXE or ZIP; no Python installation is required. NISA ↔ CLE Kai save conversion remains available.
